# Outrun for Zed (VS Code port)

This is the [Outrun VS Code theme](https://github.com/samrap/outrun-theme-vscode) by [Sam Rapaport (samrapdev)](https://github.com/samrap) converted to Zed's theme format. Outrun is inspired by the colors, style, and culture of the synthwave music scene. All colors come straight from the original theme.

Two variants are included:

- **Outrun Night (VS Code)**: `#161130` editor background
- **Outrun Electric (VS Code)**: darker `#0c0a20` editor background, higher contrast

## Installation

Search for **Outrun (VS Code Port)** in Zed's extension browser (`cmd-shift-x`), install it, then pick the theme with `cmd-k cmd-t`.
